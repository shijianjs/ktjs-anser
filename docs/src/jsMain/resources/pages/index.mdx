<ktjs-features section-title="Why this wrapper" tinted>

<ktjs-feature icon="lucide:terminal" title="Build logs, rendered">`git`, `npm`, `kotlinc` and CI logs arrive coloured by SGR escapes; one call turns them into spans a page can show.</ktjs-feature>

<ktjs-feature icon="lucide:braces" title="Three outputs, one input">HTML for display, JSON for an editor that styles each span itself, plain text for search and copy.</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="Typed end to end">The module is `external` declarations and sealed literals: options, entries and colour names are checked, not guessed.</ktjs-feature>

<ktjs-feature icon="lucide:paintbrush" title="Classes or inline colours">`use_classes` switches to `ansi-*-fg`, so the page's own stylesheet decides the palette.</ktjs-feature>

<ktjs-feature icon="lucide:link" title="Links and escaping">`escapeForHtml` for untrusted text, `linkify` for the URLs inside it — in that order.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs and demo in two languages">This site and the demo both switch between English and Chinese; the API reference is Dokka output.</ktjs-feature>

</ktjs-features>
