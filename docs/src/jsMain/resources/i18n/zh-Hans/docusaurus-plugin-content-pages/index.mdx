<ktjs-features section-title="为什么用它" tinted>

<ktjs-feature icon="lucide:terminal" title="构建日志直接上页面">`git`、`npm`、`kotlinc` 与 CI 日志都是 SGR 转义着色，一次调用就变成页面能显示的 span。</ktjs-feature>

<ktjs-feature icon="lucide:braces" title="一种输入，三种输出">要显示用 HTML，要自己给每个片段配色用 JSON，要搜索或复制用纯文本。</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="全程有类型">整个模块就是 `external` 声明与 sealed 字面量：选项、片段、颜色名都经过编译器。</ktjs-feature>

<ktjs-feature icon="lucide:paintbrush" title="class 或内联颜色">`use_classes` 切到 `ansi-*-fg`，调色板交给页面自己的样式表。</ktjs-feature>

<ktjs-feature icon="lucide:link" title="转义与链接">不可信的文本先 `escapeForHtml`，再 `linkify` 里面的链接——顺序不能反。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="文档与 demo 都是双语">本站与 demo 都能中英切换；API 文档由 Dokka 生成。</ktjs-feature>

</ktjs-features>
